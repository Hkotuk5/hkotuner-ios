# hkotuner для iPhone

Карманная версия [hkotuner](https://github.com/Hkotuk5/hkotuner) — музыкального плеера для Windows.
Ищет песни в YouTube Music и SoundCloud, играет локальные файлы и прямые ссылки на аудио.
Скачанные песни доступны без интернета. Приложение устанавливается через Sideloadly, SideStore или AltStore.
**[Скачать IPA](https://github.com/Hkotuk5/hkotuner-ios/releases/latest)** ·
**[Инструкция по установке](УСТАНОВКА.md)**

*A pocket version of the hkotuner desktop music player for iPhone, sideloaded (no App Store).*

## Что умеет

- Поиск песен, исполнителей, альбомов и плейлистов; страницы исполнителей и альбомов, подписка
  на исполнителей и «Новое у ваших исполнителей».
- «Моя волна», похожие песни, повтор песни или очереди, очередь с перетаскиванием.
- Синхронный текст песен (LRCLIB), эквалайзер на 10 полос с пресетами десктопа, одинаковая
  громкость песен, таймер сна, продолжение с того же места после перезапуска.
- Вход в свой YouTube Music (страница Google, пароль приложение не видит): перенос лайков и
  плейлистов, личные подборки на главной. Звук берётся так же, как без входа.
- Плейлисты по ссылке из YouTube и Spotify, обмен ссылками и файлами `.hkplaylist` в формате
  десктопа, обложки плейлистов, «Часто слушаю» / «Давно не слышал», статистика.
- Регистрация, вход или режим гостя при запуске. Аккаунт автоматически синхронизирует библиотеку
  и профиль между телефоном и компьютером, пока приложение подключено к серверу.
- Темы, свой фон и кадрирование аватара. Поддерживаются GIF-аватары.
- Скачивание доступных треков, свои файлы, копия библиотеки раз в неделю в «Файлы», проверка обновлений.
- Если YouTube требует подтверждение, попробуй открыть **Настройки → Плеер YouTube** и пройти
  проверку на его странице для прослушивания онлайн. Треки, доступные только через страницу YouTube,
  скачать в hkotuner нельзя.

## Как устроено

- **SwiftUI**, iOS 16+. Для части онлайн-источников используется встроенный модуль Python.
- Звук файлов с телефона идёт через `AVAudioEngine` (эквалайзер, громкость); HLS — через `AVPlayer`.
- Поиск и радио: JSON API YouTube Music (`Sources/Net/YTMusic.swift`, перенесено из
  `crates/hk-core/src/ytmusic.rs` десктопа).
- Плеер открывает локальные файлы и доступные аудиопотоки по HTTPS. В очереди он заранее
  подготавливает следующий трек. При отказе YouTube можно использовать его собственную страницу.
- Список клиентов можно обновить без новой сборки: приложение скачивает
  [`client-config.json`](client-config.json) из этого репозитория (схема в `Sources/Net/ClientConfig.swift`).
- Библиотека — `library.json` в том же формате, что на компьютере; импорт принимает копию,
  сохранённую десктопом (`hkotuner-backup`).

## Сборка

Проект Xcode генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml`.
GitHub Actions (`.github/workflows/build-ipa.yml`) на `macos-latest` гоняет тесты в симуляторе и
собирает **неподписанный** `hkotuner.ipa` (артефакт каждого запуска; для тега `v*` — релиз).
Подписывает его уже Sideloadly / SideStore / AltStore на твоём Apple ID.

На Mac локально:

```sh
brew install xcodegen
bash tools/prepare-ios-python.sh Support/PythonRuntime
xcodegen generate
open hkotuner.xcodeproj
```
