# Как поставить hkotuner на iPhone

hkotuner для iPhone нет в App Store, поэтому его ставят «сайдлодом»: ты сам подписываешь
приложение своим Apple ID и кладёшь на телефон. Mac не нужен, хватит компьютера с Windows.

## Что важно знать заранее

- **Подпись живёт 7 дней.** С бесплатным Apple ID приложение через неделю перестаёт открываться,
  пока его не переподпишешь. Это минута, библиотека и скачанные песни не пропадают.
  Платный аккаунт разработчика Apple ($99 в год) даёт год, но он не обязателен.
- **Не больше 3 таких приложений** одновременно на один бесплатный Apple ID.
- **Лучше завести отдельный Apple ID** только для этого, а не вводить основной.
  Пароль и код подтверждения вводишь ты сам, в окне программы. Никому их не пересылай.
- Нужен iPhone с **iOS 16 или новее**.

## Шаг 1. Скачать файл приложения

1. Открой репозиторий **Hkotuk5/hkotuner-ios** на GitHub.
2. Справа нажми **Releases** и скачай `hkotuner.ipa` из последней версии.
   Если релиза ещё нет: вкладка **Actions** → последний зелёный запуск → внизу **Artifacts** →
   `hkotuner-ipa`. Распакуй zip, внутри лежит `hkotuner.ipa`.

## Шаг 2, вариант А. Sideloadly (проще всего с Windows)

1. Поставь **iTunes** и **iCloud** с сайта apple.com (не из Microsoft Store): так просит Sideloadly.
2. Скачай Sideloadly **только с официального сайта** sideloadly.io и установи.
3. Подключи iPhone кабелем, разблокируй его и нажми **«Доверять этому компьютеру»**.
4. Перетащи `hkotuner.ipa` в окно Sideloadly, впиши свой Apple ID и нажми **Start**.
   Пароль и код подтверждения Sideloadly спросит сам.
5. На iPhone: **Настройки → Основные → VPN и управление устройством** → твой Apple ID → **Доверять**.
6. Включи **Режим разработчика**: **Настройки → Конфиденциальность и безопасность → Режим разработчика**
   → включить → перезагрузка → «Включить». Этот пункт появляется после первой установки.
7. Открывай hkotuner.

**Раз в 7 дней** подключи телефон и снова нажми **Start** с тем же `.ipa` (или с новой версией).
Приложение обновится поверх, любимые и плейлисты останутся.

## Шаг 2, вариант Б. SideStore: продлевать прямо с телефона

Если часто бываешь далеко от компьютера, удобнее **SideStore**: он сам продлевает подпись
на телефоне. Компьютер нужен только один раз, для первой настройки.

1. Поставь SideStore по официальной инструкции на **docs.sidestore.io**. Там всегда свежие шаги,
   они иногда меняются. Понадобится тот же отдельный Apple ID.
2. Скинь `hkotuner.ipa` на телефон (AirDrop, «Избранное» в Telegram, iCloud Drive) и в SideStore
   открой **My Apps → +**, затем выбери файл.
3. Раз в несколько дней открывай SideStore и жми **Refresh All**. Можно настроить быструю команду,
   чтобы это происходило само.

**AltStore** (altstore.io) работает похоже, но продлевает подпись через AltServer на компьютере
в той же Wi‑Fi сети.

## Что умеет hkotuner

- Поиск песен в YouTube Music и SoundCloud. Можно вставить ссылку на трек или прямую ссылку
  на аудио по HTTPS.
- При первом запуске можно войти, зарегистрироваться или продолжить без аккаунта. С аккаунтом
  изменения библиотеки и профиля автоматически синхронизируются с компьютером.
- **Моя волна**: бесконечный подбор по твоим любимым и истории. После любой песни из поиска
  дальше идут похожие.
- Локальные файлы и поддерживаемые аудиопотоки играют в фоне. Доступно управление с экрана
  блокировки, из Пункта управления и с наушников. Плеер YouTube может поставить песню на паузу
  после блокировки экрана.
- **Скачанные треки** играют без интернета. Массовая загрузка находится в
  **Библиотека → ⚙︎ → Скачать все любимые сейчас**. Возможность сохранить трек зависит от источника.
- Плейлисты, история (200 последних песен), «Не нравится» (такие песни не попадают в волну).
- Синхронный текст песен, десятиполосный эквалайзер для поддерживаемого аудио, темы и свой фон.
- Свои файлы: Библиотека → Мои файлы → «+». Или положи mp3/m4a/flac в
  **Файлы → На iPhone → hkotuner → Music** и нажми «Обновить».
- Перенос с компьютера: в hkotuner на ПК **Настройки → Данные → Резервная копия → Сохранить копию**,
  перекинь файл на телефон и выбери его в **Библиотека → ⚙︎ → Перенести с компьютера**.
  Любимые и плейлисты добавятся к тем, что уже есть. Песни из папок компьютера не переносятся,
  их можно добавить в «Мои файлы».

## Если YouTube требует подтверждение

Для прослушивания онлайн открой **Библиотека → ⚙︎ → Плеер YouTube → Открыть плеер YouTube**
и ответь на запрос на странице YouTube. Треки, которые YouTube отказался отдавать приложению,
сохранить для офлайна в hkotuner нельзя. При массовой загрузке приложение продолжит скачивать
доступные песни из других источников.

## Если песни перестали включаться

YouTube иногда меняет правила для приложений. Сначала открой **Библиотека → ⚙︎ →
«Обновить настройки YouTube»**: приложение скачает свежие параметры из репозитория без переустановки.
Если не помогло, нужна новая сборка. Её соберёт GitHub, а ты поставишь её поверх старой (шаг 2).
Скачанные любимые песни играют в любом случае.
